HOW IT WORKS

Built for reproducibility

A repeatable process, starting in Ubuntu WSL and ending with a live AWS website.

01

Build the container image

Package the complete HTML, CSS and JavaScript website into an Apache Docker image.

docker.exe build
02

Push a versioned ECR image

Authenticate Docker with Amazon ECR, add an immutable release tag and upload the image.

docker.exe push
03

Deploy the infrastructure

Review Terraform plans and deploy the networking, load balancer, IAM role and ECS Fargate service.

terraform apply
04

Verify the running website

Open the load balancer URL, check /healthz and inspect ECS service and target health.

curl /healthz

How the pieces connect

Docker builds an Apache image containing the Morays HTML, CSS and JavaScript. The image is uploaded to Amazon ECR with a unique tag, so ECS can pull the exact release selected for deployment.

Terraform provisions networking, security groups, the public Application Load Balancer, ECS task definition and ECS Fargate service. Incoming HTTP requests go through the load balancer to a running Apache container.

The load balancer routes browser requests to the healthy instances. Newly launched replacement servers must also receive the configuration through a separate automated bootstrap process.

This demonstration may start with one task. For higher availability, configure two or more tasks across Availability Zones, use private task subnets, HTTPS and appropriate monitoring.
